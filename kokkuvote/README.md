# Kokkuvõte

Git on versioonihaldussüsteem, mida kasutatakse failide ja projektide haldamiseks. Git aitab jälgida muudatusi ja võimaldab taastada vanemaid versioone. Seda kasutatakse tarkvaraarenduses väga laialt.

Commit tähendab muudatuste salvestamist Git ajaloos. Push tähendab muudatuste saatmist GitHubi serverisse. Need kaks tegevust on seotud, kuid erinevad.

Harud ehk branches võimaldavad töötada erinevate muudatustega eraldi. See aitab vältida vigade sattumist põhiprojekti. Harud on kasulikud meeskonnatöös.

Pull Request on viis muudatuste ülevaatamiseks enne nende ühendamist põhiharuga. See aitab kontrollida kvaliteeti ja vältida probleeme.

Git erineb tavalisest failide kopeerimisest selle poolest, et kõik muudatused salvestatakse ajaloona. USB-le kopeerides puudub muudatuste ajalugu.

GitHub aitab ka projektijuhtimisel. Issues võimaldavad luua ülesandeid ja jälgida nende staatust. Projects võimaldab kasutada Kanban-tahvleid töö organiseerimiseks.
