# Teema 5: Projekt

## Põhimõisted

* **Projekt** – ajutine tegevus eesmärgi saavutamiseks.
* **Eesmärk** – soovitud tulemus.
* **Risk** – võimalik probleem.
* **Meeskond** – projekti liikmed.
* **Tähtaeg** – töö lõppemise aeg.

## Mida õppisin

Õppisin, kuidas projekte planeeritakse ja juhitakse. Riskide hindamine aitab probleeme ennetada. Hea meeskonnatöö on projekti õnnestumiseks oluline.

## Näide

Rakenduse loomine on projekt, millel on kindel eesmärk ja tähtaeg.

## Riskitabel

| Risk                 | Mõju                  |
| -------------------- | --------------------- |
| Hilinemine           | Projekti aeglustumine |
| Vead                 | Lisatöö               |
| Halb kommunikatsioon | Segadus               |
