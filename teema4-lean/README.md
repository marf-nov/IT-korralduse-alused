# Teema 4: Lean

## Põhimõisted

* **Lean** – efektiivsuse parandamise meetod.
* **Raiskamine** – ebavajalik tegevus.
* **Kaizen** – pidev parendamine.
* **Väärtus** – kasu kliendile.
* **Voog** – töö sujuv liikumine.

## Mida õppisin

Õppisin, et Lean aitab vähendada raiskamist ja parandada töö kvaliteeti. Väikesed pidevad parandused võivad anda suuri tulemusi.

## Näide

Kui ettevõte vähendab liigset dokumentatsiooni, saavad töötajad kiiremini töötada.
