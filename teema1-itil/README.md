# Teema 1: ITIL

## Põhimõisted

* **ITIL** – IT teenuste haldamise raamistik.
* **Incident** – ootamatu probleem IT süsteemis.
* **Service Desk** – kasutajate tugiteenus.
* **Change Management** – muudatuste kontrollitud haldamine.
* **Problem Management** – probleemide põhjuste analüüsimine.

## Mida õppisin

Õppisin, et ITIL aitab ettevõtetel IT teenuseid paremini hallata. Sain teada, kuidas ettevõtted lahendavad probleeme ja haldavad muudatusi. ITIL muudab töö organiseeritumaks ja vähendab vigade hulka.

## Näide

Kui kooli WiFi ei tööta, registreeritakse probleem incidentina ning IT tugi hakkab seda lahendama.
